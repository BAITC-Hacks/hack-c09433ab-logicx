# Финальная проверка команды LogicX

## Текущее состояние

AI подключён к OpenAI через серверный /api/ai. Владелец проекта сообщил об успешной ручной проверке AI; остальные участники продолжают проверять интерфейс. Последняя локальная проверка: 22 теста проходят, сборка успешна. Исправлены потеря неперенесённых ответов и переполнение поля при переносе.

По уточнению организаторов, проверяющие используют собственный API-ключ. Они создают .env по .env.example либо задают OPENAI_API_KEY в окружении. Ключ команды и DEMO.md в Git не включаются. Общую готовность не объявляем, пока не получены результаты обоих участников.

## Кто что проверяет

| Ответственный | Проверка | Статус |
| --- | --- | --- |
| Владелец проекта | AI-вопросы, перенос ответов, подсказки по фактам, отказ выдумывать контакт | Проверено пользователем |
| Участник 2 | Ручная форма, рейтинг, подтверждение, публикация, фильтры и сортировка | Проверка продолжается |
| Участник 3 | Панель, редактор, отклики, выбор команд, сохранение после F5 | Проверка продолжается |

Участникам 2 и 3 API-ключ не нужен: карточка заполняется вручную. AI-кнопки без ключа покажут ошибку настройки; это ожидаемое поведение.

## Участник 2

- Создать задачу с названием и контекстом, подтвердить и опубликовать при низком балле.
- Проверить обязательные поля и сброс подтверждения после изменения.
- Проверить вклад полей, нулевой балл за прочерки, уровни 0–39 / 40–69 / 70–89 / 90–100.
- Проверить сортировку по убыванию рейтинга, фильтры темы и готовности, возврат к «Все».
- Полностью заполненная карточка должна получать 100 при достаточно подробном тексте. Название не приносит баллы.

## Участник 3

- Открыть карточку в боковой панели; проверить закрытие и Escape.
- Изменить задачу и отменить: исходные данные остаются. Подтвердить другие изменения: они сохраняются.
- Отправить два отклика от разных команд, в том числе на задачу с низким рейтингом.
- Выбрать обе команды, отклонить одну, вернуть её на рассмотрение.
- Изменить карточку с откликами, нажать F5 и проверить сохранность карточки, откликов и решений.
- Попробовать пустой план, пробелы вместо идеи и некорректную ссылку: отправка должна блокироваться.

## Как передать результат

Для каждой ошибки: действие → ожидание → фактическое поведение; добавить скриншот, если проблема визуальная. После проверки написать, какие пункты прошли, какие не проверены и какие ошибки остались. «Вроде работает» не заменяет проверку сохранения после F5.

Исправления делать в отдельной ветке от текущей main. Не заменять App, TaskDetails, TaskForm или aiService целиком файлами из старой feature/task-quality. О незакоммиченных изменениях сообщить перед обновлением ветки.

## Известные ограничения

Данные хранятся в localStorage одного браузера, роли демонстрационные. AI работает через npm run dev и npm run preview; одной статической папки dist недостаточно. Баллы студенческим командам за подтверждённый этап из шага 8 ТЗ пока не реализованы; не заявлять эту функцию на демонстрации. Вознаграждение за этап нужно отдельно согласовать по оставшемуся времени перед фиксацией финального объёма.
